How It Works

You → Message via Slack / Telegram / Discord / Signal / Web
Gateway → Routes messages, manages sessions, runs cron jobs
LLM → Claude, GPT, Gemini, local models — your choice
Tools → Shell, browser, files, web search, code execution
Skills → Plugins from ClawHub: email, calendar, GitHub, weather, etc.

Hands-On: DigitalOcean Setup

~10 minutes from zero to running agent

# Step 1: Create Droplet
# → cloud.digitalocean.com/droplets/new?image=openclaw
# Pick: 4GB RAM / 2 CPU / $24mo

# Step 2: SSH in and configure
$ ssh root@YOUR_DROPLET_IP
$ openclaw onboard --install-daemon

# Step 3: Connect Telegram
$ openclaw config edit
# → Add bot token + user ID
$ openclaw gateway restart

# Step 4: Web dashboard
$ ssh -L 18789:127.0.0.1:18789 root@YOUR_DROPLET_IP

# 🎉 You now have an always-on AI agent

The Secret Sauce: Personalization

OpenClaw agents aren't generic — they're yours.

SOUL.md — Your agent's personality & operating style
USER.md — Who you are, what you care about
HEARTBEAT.md — Proactive routines (cron-driven)
MEMORY.md — Persistent context across sessions
