OpenClaw Setup Guide

Get your own AI agent running in ~10 minutes

Messaging App

Telegram is the easiest start

No Docker experience needed. No server admin background required.

1 Create Your Droplet ~2 min

Click the link below — it pre-selects the OpenClaw 1-Click image:

→ Create OpenClaw Droplet on DigitalOcean


Settings:

  • Region: Wherever is closest to you
  • Size: 4GB RAM / 2 CPU ($24/mo) — plenty for personal use
  • Auth: SSH key (recommended) or password

Click Create Droplet and wait ~60 seconds.

2 SSH In & Configure ~3 min

Grab your Droplet's IP from the dashboard, then:

$ ssh root@YOUR_DROPLET_IP

Run the onboarding wizard:

$ openclaw onboard --install-daemon

This walks you through:

  • Setting your LLM API key (paste your Anthropic key)
  • Choosing a gateway password
  • Installing the background service (auto-start)

3 Connect Telegram ~3 min

The fastest way to start chatting with your agent:

  1. Open Telegram → talk to @BotFather
  2. Send /newbot, name it, copy the token
  3. Add it to your OpenClaw config:
$ openclaw config edit
# Add your Telegram bot token under channels.telegram.token
# Set your Telegram user ID in channels.telegram.allowFrom

Then restart:

$ openclaw gateway restart
✅ Done! Send a message to your bot. It responds. You now have a personal AI agent running 24/7 in the cloud.

4 Access the Web Dashboard ~2 min

Monitor sessions, view logs, manage config — all from your browser:

$ ssh -L 18789:127.0.0.1:18789 root@YOUR_DROPLET_IP

Then open http://127.0.0.1:18789 in your browser.

🚀 What Can Your Agent Do?

  • Answer questions from any connected messaging app
  • Run scheduled tasks — daily briefings, reminders, automated checks
  • Browse the web and summarize content
  • Execute code in a sandboxed environment
  • Install skills from ClawHub — weather, email, GitHub, calendar, and dozens more

🧩 Install Your First Skill

Skills are plugins that give your agent new abilities. Try the weather skill:

$ openclaw skill install weather
$ openclaw gateway restart

Now ask your agent "What's the weather in Austin?" and watch it work.

🎨 Personalize Your Agent

The real power: make it yours. Create these files in your workspace:

  • SOUL.md — Personality, communication style, operating principles
  • USER.md — Who you are, what you care about, your projects
  • HEARTBEAT.md — Proactive routines (morning briefings, email triage, reminders)
  • MEMORY.md — Persistent context that survives across sessions
  • TOOLS.md — Available tools, credentials, local setup

🔧 Troubleshooting

# Built-in diagnostic — checks config, API, channels
$ openclaw doctor

# Check gateway status
$ openclaw status

# View recent logs
$ openclaw gateway logs
⚠️ Common issue: If your agent isn't responding, run openclaw doctor first. It catches 90% of problems.
